# CSDC 官网介绍
CSDC 官网是借由 ChatGPT 打造的 HTML/CSS/JavaScript 静态网站，是中国最专业的神力科莎（Assetto Corsa）虚拟漂移赛事：CSDC（Community Simulated Drift Competition，原China Simulated Drift Competition）的官方网站，其内容包括但不限于：赛事历史、赛事报名、赛程安排、车手阵容和赞助商名单等。网站的后续修改可继续通过 GitHub Pages + GitHub Actions 发布，无需安装额外框架。
