CSDC 赛季车号审核前端修复（基于 csdc-website-main(4).zip）

更新文件：
- js/season-number.js：账号已通过且未撤销车手资格即可申请；增加首次缴费和跨赛季免缴费说明。
- js/season-admin.js：新增会费核实、上赛季车号归属及人工确认、同号待审数量、批准前置检查。
- js/admin.js：移除已被数据库禁用的直接授予/重新授予车手资格按钮，保留撤销。
- SQL-车号审核后台上下文.sql：新增只读管理员 RPC，为前端提供安全的审核上下文。

部署顺序：
1. 在 Supabase SQL Editor 执行 SQL-车号审核后台上下文.sql。
2. 确认执行成功后，将本 ZIP 网站文件部署到 GitHub Pages。
3. 用管理员账号打开车号审核页，检查能否读取新字段。
4. 使用专门测试账号及测试赛季进行完整流程测试，确认后才开放真实用户申请。

注意：
- 本 ZIP 中的 SQL 文件只是交付给管理员执行，不会因为部署到 GitHub Pages 而自动运行。
- 管理员人工核实会费必须先确认实际到账；本系统没有自动支付验证。
- 同号申请可以并存，但正式分配仍由数据库唯一约束限制。
- 本版没有修改 submit_registration；目前赛事报名 RPC 仍需后续补充赛事所属赛季正式车号检查。
- 本版没有完成真实 Supabase 环境的端到端测试。
- 现有优先权确认记录按申请 ID 绑定；如果原车手之后改变意愿，管理员必须重新核实并更新记录。涉及争议时请勿批准。
- 在完成审核功能和报名权限的联调之前，不要开放真实用户车号申请。
